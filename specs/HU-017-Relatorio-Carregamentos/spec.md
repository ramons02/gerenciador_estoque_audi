# Spec - HU-017 — Relatório de Carregamentos (Entradas)

**HU de origem:** HU-017
**Status:** Em elaboração

## 1. Objetivo

Como administrador, quero gerar o relatório de carregamentos por período, para acompanhar compras de carga e devoluções de vazios.

## 2. Critérios de Aceitação

- **CT-001** O relatório lista: Data, Fornecedor, Produto, Qtd Cheios Entraram, Qtd Vazios Saíram, Custo Total (RF-042).
- **CT-002** O relatório respeita o período selecionado (RF-040).
- **CT-003** O relatório pode ser exportado em Excel/CSV (RF-044).

## 3. Requisitos vinculados

- RF-042
- RF-040
- RF-044

## 4. Regras de negócio aplicáveis

- Seguir o vocabulário do domínio (Constituição §II).
- Não criar regra fora de requisitos/HUs (Constituição §X, §VI.5).
