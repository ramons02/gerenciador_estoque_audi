# Spec - HU-005 — Cadastro de Fornecedores (Distribuidoras)

**HU de origem:** HU-005
**Status:** Em elaboração

## 1. Objetivo

Como administrador, quero cadastrar fornecedores/distribuidoras (ex.: Ultragaz, Nacional), para que as entradas de caminhão sejam identificadas.

## 2. Critérios de Aceitação

- **CT-001** O cadastro captura nome da distribuidora e contato.
- **CT-002** O fornecedor fica disponível na seleção do registro de carregamento (RF-010).

## 3. Requisitos vinculados

- RF-005

## 4. Regras de negócio aplicáveis

- Seguir o vocabulário do domínio (Constituição §II).
- Não criar regra fora de requisitos/HUs (Constituição §X, §VI.5).
