# Spec - HU-016 — Relatório de Vendas (Diário/Mensal)

**HU de origem:** HU-016
**Status:** Em elaboração

## 1. Objetivo

Como administrador, quero gerar o relatório de vendas por período com as colunas padrão, para conferir as vendas do dia/mês.

## 2. Critérios de Aceitação

- **CT-001** O relatório lista: Data/Hora, Produto, Qtd, Valor Unitário, Total (R$), Forma de Pagamento, Tipo (Balcão/Entrega) (RF-041).
- **CT-002** O relatório respeita o período selecionado (RF-040).
- **CT-003** O relatório pode ser exportado em Excel/CSV (RF-044).

## 3. Requisitos vinculados

- RF-041
- RF-040
- RF-044
- RGN-008

## 4. Regras de negócio aplicáveis

- Seguir o vocabulário do domínio (Constituição §II).
- Não criar regra fora de requisitos/HUs (Constituição §X, §VI.5).
